想学 Linux，最省事的办法是在虚拟机里装一套 Ubuntu：不折腾分区、不影响现有系统，出问题删掉重建就行。本文按”安装 → 基础配置 → 包管理 → 常用命令”的顺序，把新手最常遇到的操作串成一条线。

一、用 VirtualBox 安装 Ubuntu

VirtualBox 是 Oracle 开源的虚拟机软件，能在 Windows、Linux、macOS 上跨平台运行。Ubuntu 是流行的 GNU/Linux 发行版，桌面版每两年发布一个 LTS 长期支持版本，例如 24.04 LTS，适合学习和日常使用。

安装步骤：

  1. 到官网下载 VirtualBox 和 Ubuntu 的 ISO 镜像。
  2. 打开 VirtualBox，点击”新建”，自定义名称，选择类型为 Linux，版本选对应的 Ubuntu 位数。
  3. 分配内存，一般 2~4 GB，视宿主机器配置而定。
  4. 创建虚拟硬盘，选择 VDI（VirtualBox 磁盘映像），分配方式选动态分配，容量给 60 GB 左右即可。
  5. 在虚拟机设置里挂载 Ubuntu ISO 镜像，启动后进入安装界面。
  6. 选择”中文（简体）”，点击安装，键盘布局用默认，填写用户名和密码后等待自动安装完成。

ISO 是光盘镜像。网上还有 GHO 镜像，但这类多为第三方修改版，可能预装软件或精简功能，学习用途建议用官网原版 ISO。

1.1 宿主机与虚拟机共享文件夹

要让 Windows 和 Ubuntu 之间传文件，常见做法是：

  • 先在 Windows 里把某个文件夹设为共享；
  • 在 VirtualBox 中开启该文件夹的共享功能，并安装增强功能插件（Guest Additions）；
  • 在 Ubuntu 中访问挂载点即可读写共享目录。

如果用的是 VMware，通常可以直接把文件拖拽进虚拟机，更省事。前提都是两台机器处于同一网段。

三、包管理：APT 与 Snap

Ubuntu 上主要有两套包管理工具，设计理念差别很大：

对比项 APT Snap
包格式 .deb .snap
依赖处理 依赖系统共享库 应用连同依赖一起打包
安装速度 / 体积 快、占用小 首次较慢、体积较大
更新方式 手动 apt update + apt upgrade 自动更新，可配置关闭
跨发行版 仅 Debian 系 Ubuntu、Fedora、Arch 等
隔离性 低，与系统深度集成 高，类似容器
依赖冲突 可能出现”依赖地狱” 独立打包，基本避免
版本回滚 不方便 支持快照回滚
适用场景 系统组件、服务器软件 桌面应用、开发工具

APT 更适合管理系统级软件，例如 sudo apt install nginx；Snap 适合需要频繁更新的桌面应用，例如 sudo snap install firefox。

一个常见现象：Ubuntu 22.04 默认用 Snap 安装 Firefox，即便你用 apt 命令安装，也只会装上一个指向官方 Snap 的空包，最终还是 Snap 版本。

3.1 apt 与 apt-get 的区别

apt 是较新的命令，目的是取代 apt-get 和 apt-cache，交互更友好、输出更简洁；apt-get 更底层，能精细控制安装与卸载过程。实际上 apt 包含了 apt-get，日常交互式操作推荐用 apt，写脚本时 apt-get 的行为更稳定可预期。

四、特殊权限：s、t、i、a

除了常见的 rwx（读、写、执行），Linux 还有四种特殊权限，看到 rwt、rws 这类组合时别慌：

权限 名称 作用 设置方法
s setuid / setgid 以文件所有者（常为 root）身份执行 chmod u+s 文件
t 粘滞位 只有所有者或 root 能删除，即使权限是 777 chmod +t 目录
i 不可修改 连 root 都不能改，要先去掉才能修改 chattr +i 文件
a 只追加 只能往末尾追加，不能删除，适合日志 chattr +a 文件

几个要点：

  • 设置 s 权限前必须先有 x 权限，否则不生效。未生效时显示为大写 S，生效时为小写 s。
  • t 一般出现在权限末尾（其他用户位），典型目录是 /tmp。
  • 查看 i、a 属性要用 lsattr，普通 ls -l 看不到。

对比项 vi vim
获取方式 系统自带 需安装
脚本扩展 不支持 VimScript 支持
外部命令交互 不支持 支持 :! 调用外部命令
图形界面 无 有 gVim
适用场景 资源受限、简单编辑 复杂编辑、插件扩展
