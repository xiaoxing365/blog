如果你只用过 Windows，第一次打开 Linux 终端，可能会有点懵：为什么没有 C 盘？为什么路径用斜杠而不是反斜杠？为什么装个软件还要敲命令？这些疑问很正常，因为两者虽然都是操作系统，设计思路却来自不同的传统。这篇文章就从零开始，带你认识 Linux 的来历、常见版本，以及它和 Windows 最关键的区别。

Linux 是什么：从一间大学宿舍说起

操作系统可以想象成电脑的”总管家”。它负责管理硬件、安排程序运行、给你提供操作界面。Windows 是大多数人熟悉的管家，而 Linux 是另一位风格截然不同的管家。

Linux 的诞生：1991 年的一个学生项目

1991 年，芬兰赫尔辛基大学的学生林纳斯·托瓦兹（Linus Torvalds）出于个人兴趣和学习目的，写了一个类 Unix 的操作系统的内核。当时他只是想让自己的电脑能更好地运行 Unix 那样的多任务环境，没想到这个项目后来会发展成影响全球的操作系统。

Linux 有几个与生俱来的特点：

  • 开源：源代码公开，任何人都能查看、修改和分发。
  • 免费：绝大多数发行版可以免费使用和传播。
  • 跨平台：能跑在个人电脑、服务器、手机、嵌入式设备上。
  • 多用户、多任务：多个用户同时使用、多个程序同时运行，是它设计之初就具备的能力。

一个常见的澄清：严格来说，Linus 写的是”内核”（kernel），也就是系统的核心部分。我们平时说的 Linux 操作系统，是内核加上各种工具、库和应用软件打包在一起的整体。正因为打包方式不同，才有了下面要讲的”发行版”。

类 Unix：站在巨人的肩膀上

Linux 属于”类 Unix”（Unix-like）系统。Unix 是更早出现的一套操作系统理念，强调简洁、可组合、一切皆文件。Linux 沿袭了这些思想，但实现完全独立、代码全部重写。理解”类 Unix”这三个字，就理解了大半个 Linux：它重视命令行、重视权限隔离、重视用一堆小工具配合完成复杂任务。

主流 Linux 发行版盘点

内核加上不同的软件组合，就构成了不同的”发行版”（distribution，简称 distro）。你可以把发行版理解成不同品牌的”套装”，内核是共同的发动机，但外壳、预装软件、更新策略各不相同。

几个最常听到的名字：

  • Ubuntu：基于 Debian，界面友好、安装简单，非常适合初学者和桌面用户。
  • Debian：以稳定和自由软件理念著称，是很多其他发行版的”源头”。
  • CentOS：基于 Red Hat Enterprise Linux（RHEL）的社区版本，免费且以稳定性著称，过去在服务器上非常流行。
  • Red Hat Enterprise Linux（RHEL）：商业发行版，主打企业级支持与服务。
  • Fedora：Red Hat 赞助的社区版，追求新技术，更新快，适合尝鲜。

为了让你一眼看清它们的定位，下面这张表做了对比：

发行版 上游/基于 主要特点 适合人群
Ubuntu Debian 易用、社区大、资料多 零基础、桌面用户
Debian 独立 稳定、自由软件理念 注重稳定的用户
CentOS RHEL 免费、稳定、生命周期长 服务器运维
RHEL 独立（商业） 企业支持、长期服务 企业生产环境
Fedora 独立（Red Hat 赞助） 新技术多、更新快 喜欢尝鲜的用户

需要提醒的是，CentOS 传统版本已经停止维护，其后续由 CentOS Stream 接替。新项目选型时，很多人会转向 Rocky Linux、AlmaLinux 或 Ubuntu Server。但作为入门知识，理解 CentOS 与 RHEL 的关系仍然很有价值。

想知道自己手上的系统到底是哪个发行版？有一个很实用的命令。

要解决什么：快速确认当前系统的发行版名称和版本号，避免装错软件包。

/etc/os-release 是一个纯文本文件，里面记录了系统名称、版本号等信息。cat 是”显示文件内容”的命令，uname -r 则只打印内核版本。预期效果：终端会输出类似 NAME="Ubuntu"、VERSION_ID="22.04" 的内容，你就能立刻知道自己面对的是哪套系统。

Linux 与 Windows 的核心区别

理解了发行版，接下来看两者在使用体验上的本质差异。这些差异不是”谁更好”，而是设计目标不同：Windows 追求开箱即用和大众友好，Linux 追求灵活、透明和可控。

文件系统：一棵大树 vs 多个盘符

这是最直观的区别。Windows 把磁盘分成 C 盘、D 盘等多个盘符，每个盘都有自己的根目录。Linux 则把所有磁盘、分区、设备统一挂到一棵以 / 为根的目录树下。无论是系统文件、你的文档，还是插入的 U 盘，都出现在这棵树里的某个位置，叫做”挂载点”。

打个比方：Windows 像是城市里并排的几栋楼，每栋楼有自己的门牌体系；Linux 像是一棵大树，所有枝干都从同一个树根长出来，U 盘只是临时嫁接上来的一根枝条。

Linux 常见目录的用途，先看一眼有个整体印象：

目录 作用
/ 根目录，整棵树的起点
/bin、/sbin 基础命令和系统管理命令
/etc 系统配置文件
/home 普通用户的家目录
/root 管理员 root 的家目录
/var 经常变化的数据，如日志
/tmp 临时文件
/dev 设备文件
/usr 应用程序和库文件

路径分隔符：斜杠的方向

Windows 用反斜杠 \ 分隔路径，比如 C:\Users\test\file.txt；Linux 用正斜杠 /，比如 /home/test/file.txt。所以你在 Windows 里写的路径，搬到 Linux 里要记得把反斜杠改成正斜杠。

此外，Linux 路径严格区分大小写：File.txt 和 file.txt 是两个完全不同的文件，这一点和 Windows 不一样。

权限体系：谁能读、写、执行

Linux 从设计之初就是多用户系统，每个文件和目录都带有三类权限：所有者、所属组、其他人，分别规定能否读（r）、写（w）、执行（x）。这种机制让系统能天然地隔离不同用户的数据。Windows 也有权限控制，但桌面场景中普通用户往往以管理员身份运行，感知没那么强。Linux 则鼓励你平时用普通账户，需要高权限时再临时提升。

关于权限的完整细节，会在后面的文章专门展开，这里先建立”Linux 权限更严格、更细致”的印象即可。

注册表与配置文件

Windows 有一个集中存放系统和软件设置的”注册表”，它是一个层次化的数据库。Linux 没有注册表，绝大多数配置以纯文本文件的形式分散存放在 /etc 等目录中，用文本编辑器就能查看和修改。

这种差别带来一个显著好处：Linux 的配置是”看得见、可追踪”的文本，改了什么一目了然，也方便用命令批量处理；而注册表的结构相对封闭，排查问题往往要借助专门工具。

软件安装方式

在 Windows 上，装软件通常是下载安装包、双击、一路点”下一步”。Linux 的主流做法是通过”包管理器”从软件仓库安装：一条命令，系统自动处理下载、依赖和安装。

不同发行版的包管理器不同，这点后面会详细讲。这里只需记住：用包管理器安装软件，比手动下载安装包更省心，也更容易保持系统整洁和安全。

给 Windows 用户的一点心理准备

从 Windows 转向 Linux，最大的门槛往往不是技术本身，而是习惯。你要接受几件事：路径用正斜杠、大小写敏感、很多操作在终端里完成、装软件优先用包管理器、平时别用管理员账户。

但换来的回报也很明确：系统更轻量、可控性更强、资源占用更低，尤其在服务器和开发场景中，Linux 几乎是绕不开的技能。把上面这些差异记在心里，再去看具体的命令和权限操作，就会顺畅得多。接下来的文章，我们就沿着”文件系统与权限””常用命令””文本处理与系统管理”这条线，一步步把 Linux 用起来。
