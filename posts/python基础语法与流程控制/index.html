很多人第一次接触 Python，是因为它”写起来像说话”：定义变量不用声明类型，语句结尾不用写分号，一行 print 就能看到结果。但简单不等于随便，真正写好 Python 仍要把数据类型、运算规则、流程控制和函数组织这几件事弄明白。这篇文章就按”数据 → 运算 → 流程 → 函数”的顺序，把最常用的基础语法讲清楚，所有示例都可以直接敲进解释器里试。

id()、内存管理与命名规则

id() 可以查看变量指向的内存地址。Python 采用基于值的内存管理：不同变量如果被赋予相同的不可变值，可能指向同一块地址：

Python 存储的其实是对象，变量指向谁、指向的对象是什么类型，都可以动态改变。给变量起名时：

  • 不能用 import、from 等关键字；
  • 不能包含括号、引号、斜线、反斜线、冒号、句号、问号等符号；
  • 可以用中文，但不同编码环境（Unicode、UTF-8、GBK）下容易出乱码，不建议；
  • 推荐使用英文字母、数字、_，并且大小写敏感。
