物联网平台部署看似只是”装软件、填参数”，实际牵扯本机 IP、数据库账号、IIS 站点、云端域名与端口等多处配置，任何一处填错都会表现为登录失败或数据不通。本文把部署步骤、排障路径和基础术语整理成可直接对照的速查表，适合在实训或现场部署时随手查阅。

平台部署速查

部署前的网络与账号基线

进入任何设备或平台前，先把网络基线设好。所有网络设备接入后的第一件事就是修改 IP，避免默认地址冲突。

配置项 推荐值 / 说明
中心网关 IP 192.168.1.100，掩码 255.255.255.0，网关 192.168.1.1
常用 DNS 谷歌 8.8.8.8、阿里 223.5.5.5、腾讯 119.29.29.29、CF 1.1.1.1
路由器管理地址 普联科技（TP-LINK）为 192.168.0.1 或 tplogin.cn
SQL Server 账号 用户名 sa，密码 123456
310S / 4150 / 4017 4150 默认设备地址 01，4017 默认设备地址 02
串口命名 串口名称必须固定到同一个 USB 口，不得中途更换

说明：原文涉及的软件目录位于实训平台安装包下，例如 NLE-ENC1000物联网技术应用实训平台V1.0\03_软件安装包\...，按实际安装路径替换即可。

新零售门店部署清单

新零售门店由本地客户端、数据库、IIS 站点和移动端 APP 四部分组成，按顺序配置即可。

步骤 操作要点 关键配置值
1. 安装客户端 安装包位于 03_PC客户端软件\01_新零售门店 安装完成后进入软件目录
2. 修改 config 把 IP 改为本机 IP，确认数据库名与密码 用户名 sa，密码 123456
3. 附加数据库 SQL Server Manager 中若无数据库，从 01_数据库\01_新零售门店\NLE_Supermarket_V1.0.0 附加 先确认 sa 账号可登录
4. 客户端配置 打开软件点右上角配置，IP 填本机 IP，端口填数据库端口 —
5. IIS 部署 打开 IIS 管理器添加站点，IP 为本机 IP，端口按实训要求填写，点右侧”启动” 初次打开较慢
6. 网页登录 浏览器打开站点，账号 admin、密码 admin，进入总部 务必点击浏览器”保存密码”
7. 添加门店与员工 进入门店管理后添加门店、员工，编号按实训要求填写 示例店长：张无忌 / 卡号 04 / 账号 Zwj
8. 门店 APP 配置 IP 填 api.nlecloud.com，端口 80，用户名为注册手机号，密码为云平台注册密码 项目 ID 为中心网关 ID，网关 ID 为应用 ID
9. COM 口确认 此电脑 → 右键管理 → 设备管理器 → 端口，查看串口号 与配置管理中填写的保持一致
10. 店长登录 必须用店长身份账号登录程序，admin 账号进不去 配置正确时退出后会自动进入

数据库路径要求：若需把新零售门店数据库保存到 c:\Database\，先在 SQL Server Manager 中右键最上方的机器名 → 属性 → 数据库默认位置，改好路径后再附加数据库，顺序不能颠倒。

摄像头与 RTSP 参数

摄像头 IP 用附带程序 Search Tool 查询，RTSP 相关参数基本固定。

参数 固定值 / 说明
RTSP 端口 554
RTSP 参数 11
默认用户名 / 密码 admin / admin
IP 获取方式 用 Search Tool 工具查询实际地址
添加网关时类型 选择 IPC，不是 Camera，端口 554

智能工厂部署差异

智能工厂没有 IIS 服务器，因此不需要发布站点，只需附加对应数据库并调好串口链路。

项目 智能工厂配置
IIS 不需要，跳过站点发布
数据库 附加 MS SQL Server Manager 对应数据库
C 面板双刀双掷开关 拨到下方连接串口服务器，再把 ZigBee 协调器转插到串口服务器
虚拟串口 打开虚拟串口软件，把双刀双掷开关与协调器的两个串口连接至虚拟串口；连不上就重启串口服务器
右上角配置 ADAM 的 COM 口与 ZigBee 的 COM 口按虚拟串口软件的串口号填写
量程与摄像头 转速 / 浓度范围按实训要求填写，摄像头 RTSP 参数 11、端口 554、账号密码默认 admin

双刀双掷开关的方向决定控制权归属，排障时经常用得上。

闸刀位置 串口服务器 中心网关 / 云平台
拨到上方 不能控制控制器与传感器数据 物联网中心网关与云平台可控制
拨到下方 连接的电脑可控制（虚拟串口或 VGA 物理连接均可） 边缘云网关与云平台不可控制

RGB 控制器直接并联在双刀双掷开关下方，相当于直连串口服务器，不受开关影响；若面板上执行器全部失效，先检查开关是否被拨到了下方。

云平台与边缘服务器接入

用途 域名 / IP 协议与端口
门店 APP 云平台配置 api.nlecloud.com HTTP，端口 80
云平台 / 边缘服务器 ndp.nlecloud.com（注意是 NDP，不是 UDP） TCP，8600 或 8601，长期支持
TCP 接入备选端口 ndp.nlecloud.com 或 117.78.1.201 TCP 8600 / 8700 / 8800；TLS 加密用 8601
410S 串口服务器 192.168.0.7 用户 / 密码 admin / admin

登录中心网关后要用 Android APP 鉴权；若上报数据已存在，先删除再上传，上传完成后要重启云平台，否则数据为空。

常见故障速查

SQL Manager 连接错误 53

这是部署中最高频的故障，根因通常是 TCP/IP 协议未启用。

步骤 操作路径
1 菜单 → Microsoft SQL Server 2008 R2 → 配置管理器
2 SQL Server 网络配置 → MSSQLSERVER 的协议
3 找到 TCP/IP，将其启用
找不到菜单项时 进入 C:\Windows\SysWOW64，打开 SQLServerManager10.msc；或先运行 mmc.exe，在”文件”中打开 SQLServerManager10.msc，再按上面步骤配置

登录与配置类故障

现象 排查方向
新零售门店卡死并闪退 配置不正确；退出后能自动进入说明配置正确
用 admin 进不去程序 必须用店长身份账号登录
网页端登不进去（摄像头除外） 多半是 IIS 服务未开启、数据库 IP 未改，或 config 中 IP 填错
门店管理页添加门店失败 确认浏览器已保存密码，门店编号按实训要求填写
上传后云平台数据为空 上传完成后重启云平台；鉴权上报若已存在需先删除

串口与组网故障

现象 处理办法
串口服务器重启后长时间不启动，但网口数据灯亮、电源灯不亮 关闭 C 面板电源开关后重新上电
虚拟串口连接 LED 屏失败 确认信息无误后重启串口服务器，等待片刻
ZigBee 两个灯一起闪 未组网（程序已烧写）；确认协调器也烧写好、Channel 与 PAN ID 全部统一、每个节点都装有天线
按组网按钮长时间组不上网 先按协调器上的第二个按钮（或与组网按钮一起按），再按 ZigBee 组网按钮
组网成功指示 通讯灯闪烁、另一个灯常亮
ZigBee 链路指示灯常灭 未接入网络，重新检查烧写与组网参数

术语速查

LoRa 与 LPWAN

术语 要点
LoRa 基于 Sub-GHz 频段，低功耗远距离通信，可用电池或能量采集供电，信号对建筑穿透性强
LoRa 模块参数 出厂波特率 9600，地址码 0，共 65536 个地址码可设，12V 或 24V 供电
LoRa 工作模式 四种模式；无苛刻低功耗需求时用一般模式（模式 0），配置电台时切到休眠模式（模式 3）
LoRa 网络组成 终端（内置 LoRa 模块）、网关（基站）、Server、云四部分，应用数据双向传输
LPWAN 低功耗广域网络，功耗低、覆盖广、穿透强，适合每隔几分钟收发少量数据的场景，如水运定位、路灯监测、停车位监测

物联网网关与连接器

物联网网关部署在网络边缘侧，通过网络连接与协议转换联结物理与数字世界，提供多样化接口、轻量化连接管理、实时数据分析与应用管理。

模块 作用
IoT 平台客户端代理 负责与物联网平台通信，网关内其他模块经此模块上报
Gateway 配置 Web App 网关配置工具
规则引擎 从物联网平台下载规则并在网关本地执行
连接器 连接网关与传感器网络，数量按需配置

连接器分两大类，选型时按设备接入方式判断。

类别 适用设备 典型连接器
串口连接器 通过 RS232 / RS485 / USB 接入网关 Modbus Over serial、LED Display、WIEGAND Bus（门禁韦根转 485）、ZigBee 2 MQTT
网络连接器 通过 TCP/IP 网络接入网关 Modbus Over TCP、HAIDAI BRESEE CAMERA（车牌识别）、HAIDAI Face Recognizer（门禁识别）、OMRON PLC

记忆要点：直连中心网关的设备全部选串口连接，只有经过串口服务器中转的才选串口服务器接入。

串口波特率分类与选择

分类 常见取值
标准波特率 2400、4800、9600、19200、38400、57600、115200
自适应波特率 按通信协议与传输介质自动选择，提升效率与稳定性
可编程波特率 按需自行设置，适合特殊应用场景
高波特率 46800、230400、460800、921600，适合高速数据传输

选择波特率时权衡三点。

因素 影响
传输速度 波特率越高越快，但传输错误概率上升
传输距离 波特率越高距离越短，高速传输会导致信号衰减
硬件支持 必须与设备硬件匹配，硬件不支持时无法使用高波特率

新旧设备区别

对比项 旧设备 新设备
部件安装 部分预装 线槽、电源口、插排等全部自行安装
走线方式 不一 走线全部在前面固定，采用塑料垫片与尖头螺丝
采集模块 ADAM4150、ADAM4017 取消两者，改用 IOT 采集器，由串口传输改为网络传输
网关版本 旧版 网关版本升级
