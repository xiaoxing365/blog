物联网设备接入网关时最常查的是寄存器起始地址、功能码、数据长度和采样公式，其次是账号、IP 与端口。本文按”设备 → 接线/参数 → 关键寄存器 → 配置值”横向合并同类设备，便于现场直接对照。

传感器接入与寄存器速查

IOT 网络数据采集器（nld-edu）

网线连接路由器（不能直连电脑），访问 http://nld-edu/ 查看分配的 IP，关闭 DHCP、设静态 IP 后保存重启；端口 502，绿灯为网络指示灯。网关侧连接类型选 Modbus over TCP，modbus 类型选 NLE MODBUS COMMON。

指令中 07D2 为寄存器地址，0004 为修改后地址；改完断电重新上电，用【读取 Modbus 从机地址】确认。

类型 通道 起始地址 数据长度 功能码
DI 数字量输入 1~8 03E9~03F0 0001 02
DO 数字量输出 1~8 0001~0008 0001 01
AI 电流 1~3 0DAD~0DAF 0001 04
AI 电压 1~3 0BB9~0BBB 0001 04

采样示例：红灯 502 / 从机 01 / 功能 01 / 起始 0001；光照 502 / 从机 01 / 功能 02 / 起始 03E9 / 长度 0001；噪声 502 / 从机 01 / 功能 04 / 起始 0DAD / 长度 0001，公式 6.25×R0/1000-5。

串口服务器与继电器（410S / 404D）

410S 默认 IP 192.168.0.7、admin / admin；RS485 设为 TCP Client，远程服务器填网关地址，本地/远程端口 57500 / 8800，注册类型选 MAC 注册包。网关侧加网络设备，连接器 NLE_MODBUS-RTU，端口 8800，采集间隔 3 秒，MAC 地址取 410S 配置界面。按 RGB 方式接入时连接器选 MODBUS-RTU、端口 6002、从机 07、公式 value。

404D 拨码 1~5 对应 1、2、4、8、16，全 ON 为 31、全 OFF 为 0。

通道 起始地址 功能码
IN1~IN4 0000~0003 02
OUT1~OUT4 0000~0003 01

添加时传感类型选 modbus rtu 执行器，功能号 01，起始地址 0000。

网络设备（4G / 大华）

设备 配置要点
4G 通讯终端 登录 192.168.14.200:8400；固件烧写走 系统 → 备份/升级 → 刷写新固件，可 ping IP 判断；设 IP 走 网络 → 修改 lan；云平台新增设备，标识为 4GMT 开头的 11 位数字；终端设域名 ndp.nlecloud.com、端口 8600、TCP，粘贴设备标识与密钥。执行器每次终端重启后重置
大华模块 lan1 192.168.1.108、lan2 192.168.2.108，admin / Newland123；改 IP 报错加 IPv6 DNS 2400::6001；连接器 ADAHUA ALARM，设备类型大华 8 路报警控制器，端口 3777，通道号按接线选

4G 排障：SIM 卡异常多为未插卡；基站无法连接通常是机卡绑定失败或信号弱。

继电器模块配置速查（JY-DAM404D / 0404）

主要参数与接线

参数 值
供电 DC 7~30V，触点隔离
接口 RS485 或 RS232，标准 Modbus RTU / ASCII
波特率 2400 / 4800 / 9600 / 19200 / 38400，默认 9600，格式 9600,n,8,1
地址 0255 可设；5 位拨码设 131，大于 31 用软件设
通道 四路继电器输出 + 四路开关量输入
触点容量 10A/30VDC、10A/250VAC，耐久 10 万次
工作温度 工业级 -40℃ ~ 85℃
选型 DAM0404-RS485：Modbus / RS485 / 继电器 4 / 输入 4

接线采用电脑 RS232 经 232-485 转换器（建议有源隔离）转出，A 接 A 端子、B 接 B 端子、屏蔽接 GND；多设备用双绞屏蔽线组成链型网络。地址规则为”设备地址 = 拨码地址 + 偏移地址”，出厂地址 0，通讯用广播地址 254。测试时把地址改为 254 再”读取地址”，读到 0 即通讯成功。

Modbus 寄存器映射

类型 地址 说明
线圈（01） 0x0001~0x0004 第 1~4 路继电器输出
离散输入（02） 1x0001~1x0004 第 1~4 路开关量输入
保持寄存器 4x1001 通讯波特率，默认 0，支持 0~5
保持寄存器 4x1002 备用，用户不可写
保持寄存器 4x1003 偏移地址，设备地址 = 偏移地址 + 拨码地址
保持寄存器 4x1004 工作模式，用户可存数据
保持寄存器 4x1005 延迟时间，用户可存数据

地址分区：0000109999 线圈、1000119999 离散输入、3000139999 输入寄存器、4000149999 保持寄存器。

波特率数值 0 1 2 3 4 5
对应波特率 38400 2400 4800 9600 19200 38400

改波特率或偏移地址后需重启设备并同步修改电脑串口设置。

常用 RTU 指令（广播地址 FE）

指令格式为地址 FE + 功能码 05 + 寄存器地址 + FF00（开）/0000（关）+ CRC16；RS232 为 1 对 1 总线，只有 RS485 可挂多设备。

联动模式

模式 光耦信号生效 信号取消 延迟
非锁联动 对应继电器吸合 对应继电器断开 ≤ 0.05s
自锁联动 继电器翻转 不动作 ≤ 0.05s
互锁模式 对应路启动，其他路停止 不动作 ≤ 0.05s
双击非锁联动 模块 1 输入使模块 2 继电器吸合 断开 ≤ 0.1s（9600）

非锁模式下串口操作可能被光耦状态覆盖，属正常现象。

闪开闪断

模式 行为
手动模式 每操作一次，继电器翻转一次
闪开模式 每操作一次闭合一次，时间 = 设置值 × 0.1 秒，随后断开
闪断模式 每操作一次断开 1 秒（可调），随后闭合

设置入口为聚英翱翔 DAM 调试软件的”继电器模式”下拉框。闪断闪开不能写入芯片，选定后对所有通道生效，可单独发送单通道指令。RGB 控制盒偏移地址等于设备地址，从机 07、端口 6002，红/黄/蓝对应 0000/0001/0002，功能 03、公式 value；3.0 设备不能用 JYDAM。

ZigBee 与无线模块组网速查

项目 要点
组网参数 Channel、PAN ID、设备 ID、RS485 波特率；Channel 与 PAN ID 必须全网一致
设备 ID 范围 0x0000~0x00FF，同网唯一，超出会异常
节点盒 1 路 RS485 + 1 路 USB 串口，5 路开关量输入、5 路数字量输出
出厂状态 路由设备，ID 默认 0x0001，RS485 默认 9600-8-N-1
协调器 用 ZigBeeConfigTool.exe 配置后 ID 固定 0x0000 不可改
指示灯 链接灯常亮=已入网，长灭=未入网；通讯灯闪一次=收到网络
功能键 短按切换允许入网；长按 3 秒释放后路由退网、协调器重建网络
模块 要点
多联继电器 先烧写 relay多联.hex（SmartRF Flash Programmer），旧设备白盒子、新设备 Telink；channel 与 PAN ID 同协调器；K1/K2 从左往右为 IN/COM/OUT/COM，IN 火线、COM 零线、OUT 输出；插串口线供电会失控，需拔电重启重新配对
四输入电流 较多联继电器短，无蓝色中继块；与 NS 同时出现，烧写用普通传感器固件、组网用四通道电流；端子为 GND、IN1~IN4
NB-IoT 烧写用 Flash Loader Demonstrator，拨码拨到”下载”，参数选 128K；两个模块分别烧一氧化碳与甲烷；网关协议选 LWM2M；屏显 0 未连云、1 已连，必须装天线
LoRa 模块挨着排列 7、8，频段一致，网络 ID 在五个设备间保持一致；NS 断电后环境云数据消失

485 接线速查

场景 接法
JY-DAM 与电脑 RS232 经 232-485 转换器转出，A 接 A、B 接 B、屏蔽接 GND；多设备用双绞屏蔽线链型连接
水浸传感器 485 转 232 接 PC，用 485 参数配置工具 V3.3 改址与波特率
ZigBee 节点盒 USB 转 485 线接 PC，用 ZigBeeConfigTool.exe 配置或透传
直连与虚拟串口 直接用线连电脑选 485 连接器，经虚拟串口连接选 232 接口
串口服务器改 IP 先把电脑设到同网段（如 192.168.14.x），连接后改 IP 并重启
IP 冲突 串口服务器与 UWB 网关 IP、端口相同，需让其中一个断网断电再改

GND 是地线接地端的缩写，对电源而言就是电源负极，不要接到真正的保护地。

实际配置以设备上电读取到的地址和波特率为准，表中默认值仅作初始参考。
