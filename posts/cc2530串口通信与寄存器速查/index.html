设备采集到温湿度、按键状态之后，怎么把数据送到电脑上查看？最常用、也最容易上手的方式就是串口。一根 USB 转 TTL 线，加上几行初始化代码，就能让开发板和电脑”对话”。这一章先把串口通信的原理和配置讲清楚，再把开发中经常要查的寄存器整理成速查表，写程序时随时翻一翻能省不少事。

并行通信与串行通信

微控制器和外设之间交换数据，按连线方式分为并行通信和串行通信两种。

对比项 并行通信 串行通信
传送方式 数据的多位同时发送或接收，每位一根线 数据一位接一位顺序传送
传输速度 快、效率高 相对慢
所需线缆 多，成本高 少，成本低
典型场景 早期打印机并口、芯片内部总线 串口、USB、网络通信

CC2530 对外通信主要靠串行接口，内部则大量使用并行总线，两者各司其职。

CC2530 的 USART 模块与引脚映射

CC2530 有两个串行通信接口 USART0 和 USART1，它们都能工作在异步 UART 模式或同步 SPI 模式。异步 UART 靠双方约定好的波特率来同步，只需要两根线（TX 发送、RX 接收）；同步 SPI 则额外有一根时钟线。物联网开发中最常用的就是 UART 模式。

同一个 USART 可以接到不同的引脚组合上，这由 PERCFG 寄存器决定：

引脚位置 USART0 USART1
位置 1 RX0 → P0_2，TX0 → P0_3 RX1 → P0_5，TX1 → P0_4
位置 2 RX0 → P1_4，TX0 → P1_5 RX1 → P1_7，TX1 → P1_6

选好位置后，还要通过 PxSEL 把对应引脚设为外设功能（SEL 置 1），并按需用 P2DIR 设定 USART 的端口优先级。例如用 USART0 的位置 1，就要让 P0_2、P0_3 处于外设功能状态。

五个核心寄存器

对 USART 编程，本质就是配置下面五个寄存器（x 为 0 或 1，分别对应 USART0 和 USART1）：

寄存器 英文全称 中文名称 作用
UxCSR USARTx Control and Status Register 控制和状态寄存器 选择 UART 或 SPI 模式、使能接收、查看收发状态
UxUCR USARTx UART Control Register UART 控制寄存器 设置数据位、停止位、校验位和硬件流控
UxGCR USARTx Generic Control Register 通用控制寄存器 设置波特率指数，也用于 SPI 时钟极性
UxDBUF USARTx Receive/Transmit Data Buffer 收发数据缓冲寄存器 写入即发送，收到的数据从这里读出
UxBAUD USARTx Baud Rate Control 波特率控制寄存器 设置波特率尾数，与 UxGCR 共同决定波特率

UxCSR 的几个常用位：MODE（第 7 位）为 1 选 UART、为 0 选 SPI；RE（第 6 位）为 1 使能接收；RX_BYTE（第 0 位）为 1 表示收到一个字节。UxDBUF 是双缓冲结构，写入一个字节后硬件立即开始发送，同时允许把下一个字节装入缓冲，因此连续发送时效率较高。

TTL 与 RS232 电平及波特率

电脑的串口遵循 RS-232 标准，而 CC2530 的 UART 引脚输出的是 TTL 电平，两者电气规范不同，直接相连会损坏芯片，必须经过电平转换，常用 MAX232 这类芯片完成转换。两种电平的定义如下：

电平标准 逻辑 0 逻辑 1
TTL 低于 0.8V 高于 2.4V
RS232 +5V 至 +15V -5V 至 -15V

另外要注意 DB9 接口的公头和母头引脚排列顺序不同，接线时别接反。

串口收发例程

要解决什么：让 USART0 工作在 UART 模式，以 115200 波特率接收电脑发来的数据，收到后立即回传，形成一个简单的回显测试。这里用接收中断，避免主程序一直轮询。

这里补充一个容易混淆的点：URX0_VECTOR（0x13）是接收完成中断向量，UTX0_VECTOR（0x3B）才是发送完成中断向量，接收服务函数要对应 URX0_VECTOR，并在函数里清除 URX0IF。预期效果：打开串口助手，设置 115200、8 数据位、1 停止位、无校验，发送任意字符，电脑都能收到同样的字符回显。

常用寄存器速查表

下面按功能模块整理开发中常用的寄存器，保留英文原名，方便对照数据手册。修改寄存器时优先使用位操作 |= 或 &= ~，避免覆盖其他配置位。

端口与中断寄存器

缩写 英文全称 中文名称 作用
P0 / P1 / P2 Port 0/1/2 端口数据寄存器 读取或设置各端口引脚电平
P0SEL / P1SEL / P2SEL Port Function Select 端口功能选择 0=通用 IO，1=外设功能
P0DIR / P1DIR / P2DIR Port Direction 端口方向寄存器 0=输入，1=输出
P0INP / P1INP / P2INP Port Input Mode 端口输入模式 设置上拉、下拉或三态
PICTL Port Interrupt Control 端口中断控制 设置各端口中断触发沿，0=上升沿，1=下降沿
P0IEN / P1IEN / P2IEN Port Interrupt Mask 引脚中断使能 使能端口内具体引脚的中断
P0IE / P1IE / P2IE Port Interrupt Enable 端口中断使能位 使能整个端口的中断
P0IFG / P1IFG / P2IFG Port Interrupt Flag 引脚中断标志 标记哪个引脚触发了中断，需手动清除
P0IF / P1IF / P2IF Port Interrupt Flag Bit 端口中断标志位 端口级中断标志，需手动清除
IEN0 / IEN1 / IEN2 Interrupt Enable Register 中断使能寄存器 各中断源使能开关，EA 在 IEN0 中
IRCON / IRCON2 Interrupt Request Control 中断请求控制寄存器 保存定时器、端口、USART 等中断标志
IP0 / IP1 Interrupt Priority 中断优先级寄存器 设置中断优先级
EA Enable All Interrupt 总中断使能位 全局中断总开关

说明：中断触发边沿由 PICTL 统一配置，部分资料中出现的 PxIES 并非 CC2530 的独立寄存器，查阅时以 PICTL 为准。
