电脑连不上网、远程登录被拒绝、文件传不过去——遇到这些问题，很多人第一反应是重启。其实只要会几条命令行，大多数网络故障都能快速定位。本文按”命令速查→远程连接→故障排查”的顺序，把常用招式整理成一份可以随手翻的手册。

一、端口：先把基本概念弄清

两台机器通信，IP 决定”找哪台电脑”，端口决定”找这台电脑上的哪个服务”。一台电脑的端口范围是 065535，其中 01023 是系统保留端口，留给核心服务使用；1024 以上是高位端口，由各种应用自由使用，客户端发起连接时一般随机选用高位端口。

端口 服务 说明
80 HTTP 普通网页浏览，明文传输
443 HTTPS 加密网页，基于 TLS
22 SSH 安全的远程登录与文件传输
21 FTP 文件传输
23 Telnet 远程登录，明文不推荐
3389 RDP Windows 远程桌面
445 SMB Windows 文件共享
1433 SQL Server 微软数据库服务
3306 MySQL 数据库服务
8080 HTTP 代理 / Tomcat 常见 Web 应用端口

防火墙里有入站规则和出站规则之分：别人访问你的服务走入站，你访问别人走出站。排查”服务起来了但别人连不上”时，优先检查入站规则是否放行了对应端口。

二、高频网络命令速查

2.1 地址与配置类

DNS 解析记录会被系统缓存。如果刚改完域名指向却还是访问旧地址，执行 ipconfig /flushdns 清缓存通常就能解决。

2.2 连通性与路径类

ping 通只说明网络层可达，telnet IP 端口 才能确认应用层端口是否真的开放。比如要确认服务器的 8005 端口是否畅通，用 telnet 而不是 ping。

2.3 连接与端口监听类

netstat 是排查”端口被谁占了”的利器。配合管道符 | 过滤输出，能快速定位目标端口。

2.4 名称解析类

nslookup 用来验证域名解析是否正确；nbtstat -n 可查看本机在局域网 NetBIOS 名称表中的登记情况。

2.5 路由与 ARP 类

route add 加上 -p 参数表示永久生效，系统重启后依然保留。arp -a 能看到当前局域网内已知的 IP-MAC 对应关系，排查地址冲突时很有用。

4.2 在 Windows 上启用 SSH 服务

部分 Windows 系统默认没有安装 SSH 组件。在”设置 → 应用 → 管理可选功能”中安装 OpenSSH 客户端和 OpenSSH 服务器，再到服务管理（services.msc）里找到 Open SSH Server 并启动。注意：安装组件不等于服务已启动，这一步常被忽略。

5.3 REMOTE HOST IDENTIFICATION HAS CHANGED

连接时报主机密钥变更警告，说明服务端密钥已改变（重装系统或重新生成密钥都会触发）。确认是合法变更后，删除客户端 C:\Users\用户名\.ssh 下的 known_hosts 文件即可；建议先改名备份，例如 known_hosts.backup。

5.4 通用排查清单

遇到问题按这个顺序过一遍，效率最高：

  1. 物理层：网线插好了吗？网卡灯亮吗？
  2. 地址层：ipconfig /all 看 IP、掩码、网关是否正确。
  3. 连通层：ping 网关 通不通？
  4. 解析层：nslookup 域名 能否解析？
  5. 端口层：netstat -an 看服务是否在监听，telnet IP 端口 验证可达。
  6. 防火墙层：入站规则是否放行对应端口。
  7. 认证层：密钥、权限、用户配置是否正确。

六、路由器基础：WAN、LAN 与 DHCP

家用或小型网络设备通常有两类接口：

  • WAN 口：广域网口，接光猫或上级路由器，负责”对外联网”。连接类型能自动获取 IP 就选自动获取，获取不到再手动填写 IP、子网掩码、网关和 DNS。
  • LAN 口：局域网口，接电脑、交换机等内网设备，决定路由器在内网中的 IP 位置。部分设备没有固定 WAN 口，需要指定哪个口作为 WAN，其余为 LAN；企业级设备还可能有双 WAN 口。

填写 DNS 时可以运营商提供的地址，也可以用公共 DNS，例如腾讯 119.29.29.29、阿里 223.5.5.5、谷歌 8.8.8.8（后者在部分网络环境下可能不可用）。

DHCP 服务器负责给内网设备自动分配地址。关键参数有：

参数 含义
地址池起止 可分配 IP 的范围
地址租期 IP 租用有效期，一般 2~3 小时较合适
网关 填路由器在内网中的 IP（见 LAN 口设置）
DNS 下发给客户端的 DNS 服务器地址

租期设置过短会造成频繁续租，过长则可能导致新设备接入时无地址可分配。如果设备没有 DHCP 功能，就得逐台手动配置静态 IP，并保证地址不冲突。

小结

网络排障的本质是层层缩小范围：ipconfig 看配置、ping 看连通、nslookup 看解析、netstat 看端口、route 看路径、arp 看映射，再配合组策略与防火墙规则做系统级管控。远程连接方面，记住 scp 的方向写法和 SSH 密钥的三件套——私钥、公钥、authorized_keys。遇到 port 22 refused 先查防火墙入站规则，遇到主机密钥变更先确认再清理 known_hosts。按这套清单走下来，大部分网络问题都能定位到根因。
