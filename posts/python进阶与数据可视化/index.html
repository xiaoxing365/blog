掌握了基础语法之后，下一步是让 Python 真正”干活”：把数据存进文件、把程序拆成模块、把逻辑封装成对象，最后把结果画成图给人看。这篇文章按”文件与序列化 → 模块与装饰器 → 面向对象 → 数据库与可视化”四个层次展开，每个示例都尽量给出可直接运行的代码。

小贴士：pip 换源。 安装第三方库时，默认源在国外，网络不稳定。可以加国内镜像：Linux 下创建 ~/.pip/pip.conf，Windows 下在用户目录建 pip/pip.ini，写入 [global] 与 index-url = https://pypi.tuna.tsinghua.edu.cn/simple/。阿里云、网易、中科大也有对应镜像地址，任选其一即可。

模式 含义
r 读取，默认模式，等价于 rt
w 写入，会先清空原文件
x 排他创建，文件已存在则失败
a 追加写入，不清空原内容
b 二进制模式
t 文本模式
+ 以更新（读写）方式打开

组合起来用，例如 w+ 打开并清空后可读写，r+ 打开但不清空。推荐用 with 语句，离开缩进块时文件会自动关闭：

二、模块与装饰器

模块、包与 init.py

单个 .py 文件就是模块；包含 __init__.py 的目录被视为包，导入包时实际执行的就是这个 __init__.py。同级导入常用相对写法：

也可以直接 from 包名.模块名 import 工具名。

name 与 all

原理是：文件被直接运行时 __name__ 等于 '__main__'，被别的文件 import 时则等于模块名。把不希望导入时执行的代码放进这个判断里，是 Python 的标准做法。

__all__ 是一个字符串列表，用来控制 from 模块 import * 时到底导出哪些名字：

装饰器

装饰器类似 Java 的注解，用 @装饰器名 写在函数定义上方，可以在不改动原函数的情况下增加功能：

装饰器也能带参数，例如 @repeat(3) 表示重复执行三次；Python 还内置了 @staticmethod、@classmethod 用于定义静态方法和类方法。

小结

这一篇把 Python 的应用能力串成了一条线：用 open 的模式和 pickle、struct、shelve 把数据存好，用 os、shutil 管理文件目录，用切片、sys.argv、CRC32、xlwt 处理日常任务；再把代码拆成模块和包，用 __name__、__all__ 控制可见性，用装饰器增加通用功能；进一步用类、魔法方法、私有属性和继承组织复杂逻辑；最后通过 pymysql 连接数据库，用 matplotlib、pyecharts 和 pandas 把数据变成直观的图表。到这里，Python 就已经从”会写语法”进阶到”能完成项目”了。
