关于小兴365

小兴365 是一个个人站点，分成两块：博客和工具站。

博客就是你现在在的 xiaoxing365.com，主要写建站过程中遇到的问题和折腾记录——Cloudflare 规则、Hexo 主题、DNS、SSL、硬件验证这些。不是教程站，更多是踩坑之后整理出来的笔记，自己以后翻也方便。

工具站在 xiaoxing365.top，放一些做站时顺手写的小工具。都是纯前端，打开就能用，不用注册，不收集数据。

关于我

一个普通的技术爱好者，平时折腾服务器、域名、静态站点，偶尔写点东西记录一下。主攻 Java 后端，也碰一点前端和 C++，编程启蒙是 Minecraft。
